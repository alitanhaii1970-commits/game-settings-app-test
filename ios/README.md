# PC Max — نسخه‌ی iOS (پروژه‌ی تست)

پورتِ کامل و بومی (SwiftUI) نسخه‌ی اندروید PC Max، مخصوص آیفون. کاملاً جدا از
اپ اندروید و از پروژه‌ی تست خودش (`com.gamesettings.app.test`) — به همون
Firestore فعلی وصله (فقط خواندن) و لیست بازی‌ها/فونت‌ها/زبان‌ها/قدرت سیستم
همه دقیقاً مثل اندروید کار می‌کنن.

## این چیه؟ فایل نصبی (.ipa) بدون امضای اپل

هر بار push به `main`، گیت‌هاب Actions به‌صورت خودکار:
1. با XcodeGen پروژه‌ی Xcode رو از روی `project.yml` می‌سازه (نیازی به فایل
   `.xcodeproj` توی ریپو نیست).
2. بدون هیچ حساب توسعه‌دهنده‌ی اپل، یک build **بدون امضا** می‌گیره.
3. اون رو به فرمت `.ipa` بسته‌بندی می‌کنه: `PCMax-ios-<شماره‌build>.ipa`.
4. توی **همون صفحه‌ی Release** که APK اندروید هم هست آپلود می‌کنه.

## نصب روی آیفون

فایل `.ipa` خودش قابل‌نصب نیست (چون امضا نشده). با یکی از این دو ابزار نصبش کن:

- **Sideloadly** (ویندوز/مک) — ساده‌ترین راه: آیفون رو با کابل وصل کن، فایل
  ipa رو بکش تو، Apple ID (رایگان) بزن، نصب می‌شه.
- **AltStore** — یه‌بار نصب اولیه با کامپیوتر می‌خواد، ولی بعدش می‌تونه از
  روی خود گوشی (با AltServer روی کامپیوتر روشن و هم‌وای‌فای) آپدیت رو بگیره.

⚠️ **محدودیت واقعی اپل، نه این پروژه:** با Apple ID رایگان، اپ **هر ۷ روز**
منقضی می‌شه و باید دوباره با همون ابزار نصب بشه. AltStore می‌تونه این تمدید
رو خودکار انجام بده. برای نصب همیشگی و بدون این محدودیت، تنها راه یا حساب
توسعه‌دهنده‌ی پولی اپله ($99/سال) یا TrollStore (فقط iOS ≤ 17.0، و فقط اگه
گوشی نسخه‌ی قابل‌جیل‌بریک/exploit داشته باشه).

## بررسی آپدیت داخل خودِ اپ

دکمه‌ی «بررسی آپدیت» توی تنظیمات، آخرین Release گیت‌هاب رو چک می‌کنه. اگه
نسخه‌ی جدیدتری پیدا کنه، لینک دانلود ipa رو تو Safari باز می‌کنه — نصب نهایی
بازم باید با AltStore/Sideloadly انجام بشه (اپل اجازه‌ی نصب خودکار خارج از
اپ‌استور رو نمی‌ده، درست مثل محدودیت مشابه در اندروید برای نصب خارج از Google
Play، با این تفاوت که سمت اپل سخت‌گیرانه‌تره).

## اگر روزی مک داشتی (توسعه‌ی محلی)

```bash
brew install xcodegen
cd ios
xcodegen generate
open PCMax.xcodeproj
```

## ساختار پروژه

- `PCMax/Core/` — مدل داده، ارتباط با Firestore، کش عکس، زبان‌ها، تم و رنگ‌ها،
  بررسی آپدیت.
- `PCMax/Views/` — لیست بازی‌ها، جزئیات بازی، تنظیمات، ورود اولیه، پیش‌نمایش عکس.
- `PCMax/Resources/` — فونت‌ها (همون ۴ فونت باندل‌شده‌ی اندروید) و آیکون/لوگو.
- `project.yml` — کل تعریف پروژه‌ی Xcode (به‌جای فایل باینری `.xcodeproj`).

## یک تفاوت کوچک و آگاهانه با اندروید

توی اندروید ۴-۵ تا پیام (مثل «لیست به‌روز شد»، «بازی‌ای با این اسم پیدا نشد»)
همیشه فارسی نشون داده می‌شن، حتی وقتی زبان اپ روی انگلیسی باشه (این یک نکته‌ی
جا‌مونده در همون کدِ اندرویده). توی نسخه‌ی آیفون این پیام‌ها رو درست دوزبانه
کردم. اگه ترجیح می‌دی دقیقاً همون رفتار (فارسیِ ثابت) باشه، بگو تا هماهنگش کنم.
